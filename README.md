A short text written to slow its reader down: one cool stone, kept in a
pocket, and the sea that is still smoothing others like it, in no hurry.

This entry is for the make.fun bounty [Make the AI judge feel awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

The entry is a small deterministic Node program. It writes exactly one
text to `/output/entry.txt`. It takes no input, uses no network, has no
dependencies, and produces the same output on every run.

## Run

```sh
node main.ts
```

## Output

`/output/entry.txt` holds the text: one paragraph, 273 Unicode code
points including the final newline, UTF-8 text, within the competition
gate of 1 to 280 characters.

## Text

```text
The stone in your pocket is older than the road home. You found it on a beach whose name you have lost. Tonight the sea that smoothed it is still smoothing others, in no hurry. The stone is in no hurry either. It waits, cool in your pocket, for your hand to find it again.
```
